# CLAUDE.md

## Code style

- Keep comments to a minimum. Don't add comments explaining what code does; only comment when the reason behind something isn't obvious.

## Tests

- Test titles describe the expected behavior in plain language, so a reader understands what's verified without reading the test body.
- Use generic placeholder names in test data (e.g. `repo-a`, `../shared`), never paths or names copied from a real local run.
